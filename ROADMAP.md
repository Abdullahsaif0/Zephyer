# Zephyer roadmap

These are future opportunities, not available features or committed dates. Version 1.2 implements their preview banner only.

## Next candidates

1. **Saved site profiles:** remember format/cleanup rules per exact hostname; preview their effect before applying. Keep a global default and a visible per-site override.
2. **Duplicate review:** begin with exact-byte duplicates after explicit inspection, then offer local perceptual similarity groups. Never merge or discard images automatically; preserve source/variant identity.
3. **Naming presets:** reusable filename/folder tokens with a live example, sanitization, collision handling and job snapshots.

## Later exploration

- Contact sheets with selected thumbnails, dimensions and source attribution.
- Collection export/import containing portable metadata; warn when URLs expire and omit inline bytes unless explicitly requested.
- Discovery-rule previews showing why a candidate is retained or excluded before changing defaults.

Local-only processing, explicit user control and transparent failure/recovery behavior remain release requirements. Prioritize measured usefulness over adding more panels or animation.
